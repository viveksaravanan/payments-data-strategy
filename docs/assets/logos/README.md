# Merchant logos (Section 1 map)

Drop a logo file per banner here and the map's detail card will use it, falling
back to a colored dot if the file is missing:

  KRG.png  ACM.png  WDX.png  CFA.png  TBL.png  BKG.png

PNG or SVG with a transparent background works best (rendered ~30px tall).
These are not committed by default — add your own licensed/approved assets.
